# Custom OS - نظام تشغيل مخصص

## نظرة عامة
مشروع نظام تشغيل متكامل من الصفر (From Scratch) بمعايير احترافية.

### الأهداف الرئيسية:
1. ✅ Bootloader كامل
2. ✅ Kernel منطقي وفعال
3. ✅ نظام إدارة الذاكرة (Memory Management)
4. ✅ معالج المقاطعات والمؤقتات
5. ✅ نظام الملفات المتكامل
6. ✅ جدولة العمليات
7. ✅ واجهة رسومية بسيطة

## البنية الأساسية:
```
custom-os/
├── bootloader/       # مرحلة الإقلاع
├── kernel/           # نواة النظام
├── arch/             # معمارية x86_64
├── drivers/          # برامج التشغيل
├── fs/               # نظام الملفات
├── mm/               # إدارة الذاكرة
├── libc/             # مكتبة C
├── shell/            # shell بسيط
├── gui/              # الواجهة الرسومية
├── tools/            # أدوات البناء
├── docs/             # التوثيق
└── Makefile          # ملف البناء الرئيسي
```

## البيئة المطلوبة:
- **نظام التشغيل**: Linux/macOS/Windows (WSL2)
- **المجمع**: GCC للمعمارية i686-elf
- **أدوات**: nasm, grub, xorriso, qemu
- **اللغات**: Assembly + C

## المراحل:

### المرحلة 1: الإقلاع الأساسي (Weeks 1-2)
- Bootloader بسيط
- أول kernel مع طباعة رسالة
- إعداد GDT و IDT

### المرحلة 2: معالج المقاطعات (Weeks 2-3)
- معالجات المقاطعات
- نظام المؤقتات
- معالج لوحة المفاتيح

### المرحلة 3: إدارة الذاكرة (Weeks 3-5)
- Paging والذاكرة الافتراضية
- Heap allocator
- Virtual Memory Management

### المرحلة 4: نظام الملفات (Weeks 5-7)
- VFS (Virtual File System)
- دعم ext4, FAT32, NTFS
- عمليات القراءة والكتابة

### المرحلة 5: جدولة العمليات (Weeks 7-9)
- عمليات وخيوط
- Scheduler
- Context switching

### المرحلة 6: واجهة رسومية (Weeks 9+)
- Framebuffer graphics
- نافذة إدارة بسيطة
- تفاعل المستخدم

## التطوير:
```bash
# التجميع
make

# التشغيل في QEMU
make run

# التنظيف
make clean
```
